#### Свойства информации
##### 1 Достоверность

##### 2 Полнота

##### 3 Актуальность

Информация должна быть свежей и свосвременной.
Устаревшие данные никому не интересны и не представляют собой ценности.

Этот параметр опирается на нужды и интересы того, кто пользуется информацией.
Применение данных должно быть уместно и рационально.

**Потоки данных**
 Потоки данных (data flow) - направление перемещения данных от одного участка кода к другому
 Это может быть представлено как последовательная цепочка операций, где результат одной операции становится входными данными для следующей
 Основная цель потока данных - обеспечить эффективное и надёжное перемещение данных из источников в целевые системы, где они могут быть использованы для отчётности, анализа, машинного обучения и других приложений, основанных на данных
**Виды потоков данных**
  - Потоки для пакетной обработки - обрабатывают данные большими порциями через определённые интервалы времени (ежечасно, ежедневно, еженедельно)
  - Потоки для интеграции данных - объединяют данные из нескольких разнородных источников в единое предстваление. Часто включают процессы ETL или ELT (Extract, Load, Transform) для извлечения данны источников, их преобразования в соответствии с общей схемой или форматом и загрузки в централизованное хранилище данных.
  - Облачные потоки данных - используют возможности и сервисы, предоставляемые облачными платформами, для создания масштабируемых решений для обработки данных.

В DataLens агрегация выполняется с помощью измерений и показателей:

**Тема: Табличный процессор LibreOffice Calc**

### Текст
LibreOffice Calc - приложение предназначено для выполнения автоматизированных математических, статистических экономических и других расчётов, для построения графиков и диаграмм, для работы с базой данных, сводными таблицами и многого другого.
 Calc - электронные таблицы LibreOffice, состоящие из определенного числа листов

**Виды данных**
 Постоянные значения - числа, символы, текст.
 - Текстовые данные содержат в себе текст, числа и символы. Текст автоматически выравнивается в ячейке по левому краю
 - Числовые данные - только цифры и десятичный разделитель (заяпятую)
 - Формулы - инструкции для вычислений, начинаются со сназа "=", содержат в себе числа, адреса ячеек, математические операции и функции

**Формулы**
 Под формулой в электронной таблице понимают выражение, состоящее из операндов(числа, тексты, которые вводятся в двойных ковычках, логические значения, значения ошибки, ссылки, строенные функции Calc) и операций

**Ссылка, диапазон**
 **Ссылка** - элемент формулы, который который используется тогда, когда надо сослаться на какую-нибудь ячейку таблицы.
 **Диапазон** - прямоугольной области, состоящей из нескольких (или одного) столбцов и нескольких (или одной) строк.

**Адрессация ячеек**
 Бывают случаи, когда ссылки, используемые в формуле, не нужно изменять или нужно изменять в ссылке только имя столбца или номер строки.
  Для решения всех этих задач в Calc имеются ссылки трёх типов: относительные, абсолютные, смешанные (частично абсолютные) 

**Относительный адрес ячейки**
 Относительным называются ячейки которые при копировании автоматически изменяют номер строки и или изменяют имя столбца на следующий номер или следующее имя
**Абсолютный адрес ячейки**
 Адреса ячеек, не изменяющиеся при копировании, называются абсолютными. Для перевода адреса ячейки из отностиельного вида в абсолютный, при вводе формул, перед номером строки или именем столбца нужно ввести знак "$". Можно также использовать клавишу F4
**Смешанный адрес ячейки**
 Существует также понятие смешанной (частично абсолютной) ссылки: если при копировании и перемещении не меняется имя столбца или номер строки.

**Мастер функций**
 Помимо простых формул можно работать и с функциями. Функции используются для автоматизации работы пользователя.

**Сортировка**
 Сортировкой называется изменение порядка строк в списке в соответствии с заданными условиями. Целью сортировки является упорядочене данных
 
 Сортировка применяется в случаях, когда необходимо, чтобы строки имели определённую последовательность. Сортировка выполняется: командой

**Фильтрация**
 Фильтрация - процесс сокрытия всех строк базы данных, кроме тех, которые удовлетворяют определёнными критериям. Её применение целесообразно в тех случаях, когда предпочтительне работать с подмножеством базы данных - ограниченной группой записей
 В Calc существует несколько разновидностей фильтрации:
  - автофильтр: фильтрация по одному критерию
  - стандартный фильтр: фильтрация по нескольким критериям
  - расширенный фильтр: фильтрация по диапазону критериев

**Промежуточные итоги**
 Промежуточные итоги - удобный способ обобщения и аналза данных на рабочем листе. При подведении промежуточных итогов таблица разбивается на несколько групп строк с одинаковыми значениями одного поля и по каждой группе подводятся итоги, а затем - итог по всей таблице
