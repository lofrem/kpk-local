**Тема: Электрическая цепь. Ток, напряжение, ЭДС, мощность. Основные элекменты электрических цепей и их параметры.**

###  Текст
Электрическая цепь - это замкнутый путь из элементов и устройств(или совокупность путей). по которому электрический ток может протекать от источника энергии к поребителю и обратно.

Электрические цепи состоят из:
 - источников электрической энергии
 - потребителей
 - соединительных проводов
 - 

3 состояния цепи:
 - Разрыв
 - Режим нагрузки
 - Короткого замыкания


Элементы делятся на:

| пассивные     | активные          |
| ------------- | ----------------- |
| резистор      | источники питания |
| конденсатор   | транзистор        |
| индуктивность | диод              |

Коммутационные и защитные элементы
 - выключатель
 - предохранитель

Соединительные элементы
 - проводники(дорожки на плате)

Цепи:
 - Ветвь - участок электрической цепи, по которому протекает один и тот же ток
 - Узел - место соединения 3х+ числа ветвей
 - Контур - любой замкнутый путь образованный узлами и ветвями

Классификация электрической цепи:
 - по виду тока:
  - постоянного тока
  - переменного тока

 - по составу элементов:
  - активные цепи
  - пассивные цеп
  - линейные цепи
  - нелинейные цепи

 - по характеру распределения параметров:
  - с сосредоточенными параметрами
  - с распределенными параметрами

 - по числу фаз(для переменного тока):
 - однофазные
 - многофазные(в основнов трехфазные)

Источники
 - первичный 
  - электромеханические
  - электрохимические
  - термоэлектрические
 -  вторичный
  - преобразователи

Типы схем:
 - структурная
 - функциональная
 - принципиальная
 - монтажная
