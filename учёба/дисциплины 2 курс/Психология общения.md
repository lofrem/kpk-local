Виды и Типы общения 
По своим формам и видма общение чрезазнообразно можно говорить прямо и косвенно, непосредственном, опосредованном вербальном(словесном) и невербальном общении

Различают межличностное и массовое общение межперсональное и ролевое
В случае ролевой Коммуникации устное выступает как носители ролей(учитель-ученик, директор-учитель)

Схема особенности общения

| сторона                       | Общение | функции                             |
| ----------------------------- | ------- | ----------------------------------- |
| межличностная                 |         | прагматическа                       |
| когнитивная                   |         | формирования и развития             |
| коммуникативно-информационная |         | подтверждения                       |
| эмотивная                     |         | организации и поддержания отношения |
| поведенческая(конативная)     |         | внутриличностная                    |

Прагматическа - реализуется при взаимодействии людей в процессе совместной деятельности
